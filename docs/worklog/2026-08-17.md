### 2. DB 스키마 (`feat/db-schema`)

ERD를 SQL로 옮기고 JPA 엔티티까지 작성했다.

- `server/src/main/resources/db/schema.sql` — 테이블 10개
- JPA 엔티티 16개

| 패키지 | 클래스 |
| --- | --- |
| `common` | `BaseEntity` |
| `member` | `Member`, `Gender`, `PlayerClass` |
| `equipment` | `Equipment`, `EquipmentType`, `MyRacket`, `MyShoe`, `RacketStringHistory`, `RacketGripHistory` |
| `equipment.model` | `RacketModel`, `ShoeModel`, `StringModel`, `GripModel`, `RacketWeight`, `GripType` |

ERD 원본에서 수정한 것:

- 테이블명 통일 — `string` → `string_model`, `grip` → `grip_model`, `my_shoes` → `my_shoe`
- `grip.Field` → `grip_model.type` (컬럼명 실수)
- 모든 PK에 `AUTO_INCREMENT`, FK 제약 10개 추가
- `member.login_id` / `nickname` / `email`에 UNIQUE 추가 (없으면 같은 아이디로 중복 가입 가능)
- `my_racket.equipment_id` / `my_shoe.equipment_id`에 UNIQUE (1:1 보장)
- `ENUM` → `VARCHAR` + `COMMENT` (JPA `@Enumerated(EnumType.STRING)` 대응, 값 추가 시 `ALTER TABLE` 불필요)
- 한글 ENUM 값을 영문으로 — `MALE`/`FEMALE`, 급수는 `S`, `A`~`F`
- 라켓 무게는 `U2`~`U6` (Java enum 상수가 숫자로 시작할 수 없음)
- `updated_at`에 `ON UPDATE CURRENT_TIMESTAMP` 추가

### 3. 회원가입 API (`feat/auth-signup`)

`POST /api/members/signup`

- `SecurityConfig` — `BCryptPasswordEncoder` 등록
- `MemberRepository`, `MemberService`, `MemberController`, `SignupRequest`
- `ApiExceptionHandler` — 검증 실패·중복을 400 + 메시지로 변환
- 비밀번호는 BCrypt 단방향 해시로 저장
- 의존성 추가: `spring-boot-starter-security`, `spring-boot-starter-validation`

### 4. JWT 로그인 API + 앱 연동 (`feat/auth-login`)

`POST /api/auth/login` → `{ accessToken, nickname }`

- `JwtProvider` — 토큰 발급·검증 (HS256, 만료 7일)
- `JwtAuthenticationFilter` — `Authorization: Bearer` 헤더 처리
- `AuthController`, `AuthService`, `LoginRequest`, `LoginResponse`
- `SecurityConfig` — 세션 STATELESS, 회원가입·로그인만 허용하고 나머지는 인증 필요
- 의존성 추가: `jjwt` 0.12.6
- 앱: `http` 패키지, `auth_api.dart`, `LoginScreen`을 `StatefulWidget`으로 변경

## 결정한 것

- **인증 방식** — JWT. 모바일 앱이라 세션/쿠키보다 자연스러움
- **토큰 구성** — 액세스 토큰 하나만 (만료 7일). 리프레시 토큰은 나중에 필요하면 추가
- **로그인 실패 메시지** — 아이디가 없든 비밀번호가 틀리든 동일한 메시지. 가입된 아이디 목록이 노출되지 않도록
- **엔티티에 `@Setter` 안 씀** — 변경 감지로 의도치 않은 UPDATE가 나가고 추적이 어려움. 필요해지면 `changePassword()` 같은 목적별 메서드를 추가
- **`ddl-auto: validate`** — 스키마는 `schema.sql`이 원본, 엔티티가 어긋나면 서버가 안 뜨게
