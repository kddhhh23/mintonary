# 민터너리 인스타그램 스타터 팩

## 프로필

- 프로필 이미지: `profile.png`
- 이름: `민터너리 | 배드민턴 기록 앱`
- 사용자 이름 후보: `mintonary`, `mintonary.app`, `mintonary_kr`

### 소개 문구

```text
🏸 나의 배드민턴 다이어리
운동·레슨·대회 기록
라켓·신발·지출 관리까지
👇 민터너리 베타 테스트
```

출시 전에는 베타 신청 폼을, 출시 후에는 스토어 주소를 프로필 링크에 연결한다.

## 게시 순서

`posts` 폴더의 `01`부터 `09`까지 순서대로 게시한다. 인스타그램 프로필에서는 최신 게시물이 앞에 표시되므로 최종 그리드는 다음과 같다.

```text
09 베타 모집  | 08 빠른 기록 | 07 지출
06 교체 관리  | 05 장비 관리 | 04 캘린더
03 기록 종류  | 02 질문      | 01 브랜드 소개
```

각 게시물의 본문은 `captions.md`에 있다. 게시 직전 `[베타 신청 링크]` 자리만 실제 주소로 교체한다.

## 권장 운영

- 한꺼번에 모두 올리기보다 첫날 01~03, 이후 하루 1개씩 게시
- 08은 정지 이미지 게시물뿐 아니라 실제 앱 화면 녹화를 붙인 릴스 표지로도 사용
- 댓글과 스토리 투표로 원하는 기능을 물어 초기 사용자 의견 수집
